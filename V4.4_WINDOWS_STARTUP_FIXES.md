# Career Suite v4.4 — Windows startup fixes

This build focuses on preventing the opaque `npm run dev:server exited with code 1` failure on Windows.

## What changed

- Removed the native `better-sqlite3` dependency. Accounts, resume reviews, applications, and resume versions now persist in `server/data.json`.
- Added `npm run check:server` preflight validation for the Node version, `.env` location, and uploads directory.
- Added a development-only temporary JWT secret when `JWT_SECRET` is missing. Production still requires an explicit secret.
- Added a clear `EADDRINUSE` message when port 4000 is already occupied.
- Kept the v4.3 PDF.js TrueType-warning fix.

## Recommended clean start on Windows

```powershell
npm ci
npm run check:server
npm run dev
```

If port 4000 is already occupied:

```powershell
taskkill /F /IM node.exe
npm run dev
```

For persistent sessions and Gemini features, copy `server/.env.example` to `server/.env` and fill in `JWT_SECRET` and `GEMINI_API_KEY`.
