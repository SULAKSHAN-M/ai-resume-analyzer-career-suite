# v4.6.1 — Login viewport fix

## Changes
- Redesigned the authentication page as a dedicated full-viewport screen.
- Removed the global navigation and global footer from `/auth` so the login page does not become taller than the viewport.
- Added responsive compact spacing for shorter desktop and mobile displays.
- Kept the login/register flow, authentication store calls, password visibility control, and validation behavior.
- Retained the developer credit and quick links to FAQ, Privacy, Terms, and Developer Story.
- Added viewport-based root layout behavior on `/auth`; all other routes retain the global footer.

## Verify locally
1. Run `npm install`.
2. Configure `server/.env` from `server/.env.example`.
3. Run `npm run dev`.
4. Open `http://localhost:5173/auth` and confirm the page fits the viewport without page-level scrolling.
5. Test both desktop and mobile widths, Sign in/Create account tabs, password visibility, and terms/privacy links.
