# v4.6 — Modern Career Suite UI

This version modernizes the shared interface while preserving the existing resume-analysis, AI, job-search, resume-version, and application-tracker workflows.

## Interface changes

- Responsive sticky navigation with a mobile menu and relevant workspace tabs.
- Modern sign-in and registration view with password visibility control, native form validation, clear error states, and links to legal pages.
- Global footer. “Designed & Developed by SULAKSHAN M” is aligned to the lower-left; the right side contains the product tagline and copyright.
- New public Developer Story, FAQ, Privacy Policy, and Terms of Use pages.
- Registered catch-all route and branded 404 view using the supplied illustration.
- Updated visual tokens, typography, spacing, focus states, and reduced-motion behavior.

- `/privacy`

All existing application routes remain registered.

## Install and run on Windows

```powershell
npm install
Copy-Item .\server\.env.example .\server\.env
notepad .\server\.env
npm run dev
```

Set `JWT_SECRET` to a newly generated strong random value and `GEMINI_API_KEY` to your own API key. Keep those secrets in `server/.env` only; never upload or commit that file. Pick model IDs that are currently available to your Google AI account.

For a fresh JWT secret, run:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## Before a public deployment

- Confirm the selected hosting platform can run the Express API as a persistent Node process.
- Use persistent private storage for user records and resume files; do not depend on ephemeral function storage.
- Review `server/.env.example` and configure all production variables in the host's secret manager.
- Rotate any API key or JWT secret that was previously committed, pasted into a chat, or included in an archive.
- Review the Privacy Policy and Terms of Use against the real deployment, provider terms, applicable jurisdiction, and support/contact details. They are informative templates, not legal advice.
- Run `npm run typecheck`, `npm run build`, and `npm audit` before shipping.
