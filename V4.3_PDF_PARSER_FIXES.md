# v4.3 PDF parser fixes

This release cleans up non-fatal PDF.js/TrueType font warnings from the server ATS parser.

## Fixed

- Suppresses PDF.js internal `TT: undefined function` and `TT: invalid function id` font-hint warnings by using errors-only PDF.js verbosity per document.
- Does **not** globally disable `console.warn`; genuine ATS/PDF extraction failures are still logged.
- Preserves detected PDF line endings when reconstructing resume text, improving section-heading/date detection for deterministic ATS scoring.
- Cleans up PDF.js page/document resources after extraction.
- Marks an empty machine-readable PDF as `extractionOk: false` instead of pretending extraction succeeded.

No API keys or user files are included in the release ZIP.
