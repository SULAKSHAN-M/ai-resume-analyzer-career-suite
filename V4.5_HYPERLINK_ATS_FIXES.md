# v4.5 ATS hyperlink detection fix

This build fixes false ATS contact warnings for resumes exported from Microsoft Word, Canva, and similar tools where the visible text says `LinkedIn`, `GitHub`, or `Portfolio` but the actual URL is stored only as a PDF link annotation.

## Changes

- `server/lib/ats.js` now calls `page.getAnnotations()` while reading each PDF page.
- External `http(s)` links and `mailto:` annotations are collected without changing PDF.js global logging.
- ATS contact scoring accepts embedded annotations as evidence of a web profile/link.
- Visible `LinkedIn`, `GitHub`, `Portfolio`, and `Website` labels near the top of the resume provide a conservative fallback when a PDF export strips annotations.
- ATS output now includes `contactDetection` with email, phone, LinkedIn, GitHub, portfolio/website, and embedded-link results.
- The ATS breakdown UI displays these signals so users can see exactly what was detected.

## Note

For best hyperlink preservation, export from Word using **Save As / Export to PDF** rather than printing through a PDF printer. Some print-to-PDF workflows flatten or remove link annotations.
