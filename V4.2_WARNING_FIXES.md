# v4.2 Development Warning Cleanup

This release cleans the React Router/Vite development console warnings reported in v4.1.

## Changes

- Pinned `react-router`, `@react-router/dev`, and `@react-router/node` to `7.18.4`.
- Pinned Vite to `8.3.0`.
- Enabled all five documented React Router v8 future flags while remaining on React Router 7:
  - `v8_middleware`
  - `v8_splitRouteModules`
  - `v8_viteEnvironmentApi`
  - `v8_passThroughRequests`
  - `v8_trailingSlashAwareDataRequests`
- Added `npm run reinstall` to remove stale `node_modules` directories and run a clean `npm ci`.
- Kept SPA mode (`ssr: false`) and the existing Express API architecture unchanged.

## Recommended first run

```bash
npm ci
npm run dev
```

If upgrading an existing local folder rather than extracting to a new one:

```bash
npm run reinstall
npm run dev
```
